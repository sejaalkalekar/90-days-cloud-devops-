# 📅 Day 06 — Linux File Management Challenge

**Date:** 01 August 2026

---

# 🎯 Objective

Practice essential Linux file and directory management commands by completing a real-world scenario that simulates organizing project files for different departments within a company.

---

# 📝 Project Scenario

Imagine joining **ABC Technologies** as a Linux Administrator.

Your manager assigns you the task of organizing project files for multiple departments. The objective is to create a clean directory structure, manage files efficiently, and perform common file operations using Linux commands.

---

# 📚 Topics Covered

* Creating directories
* Creating files
* Navigating the Linux file system
* Copying files and directories
* Moving and renaming files
* Deleting files and directories
* Searching for files
* Viewing file contents
* Understanding file permissions
* Compressing files

---

# 💻 Hands-on Tasks Performed

During this project, I completed the following tasks:

* Created a project workspace
* Created multiple directories for different departments
* Created sample project files
* Organized files into the appropriate folders
* Copied files to another location
* Moved and renamed files
* Removed unnecessary files and folders
* Verified the directory structure after each operation
* Practiced viewing file contents
* Checked storage usage and disk information
* Compressed project files for backup

---

# 🛠️ Linux Commands Practiced

| Category             | Commands                                    |
| -------------------- | ------------------------------------------- |
| Navigation           | `pwd`, `cd`, `ls`                           |
| Directory Management | `mkdir`, `rmdir`                            |
| File Management      | `touch`, `cp`, `cp -r`, `mv`, `rm`, `rm -r` |
| File Content         | `cat`, `less`, `echo`                       |
| Search               | `find`, `grep`                              |
| File Information     | `wc`, `du`, `df`                            |
| Permissions          | `chmod`, `ls -l`                            |
| Compression          | `tar`, `gzip`                               |

# ⚠️ Challenges Faced

* Remembering the differences between `cp`, `mv`, and `rm`
* Understanding when to use `rm -r` versus `rmdir`
* Verifying the directory structure after multiple file operations

---

# ✅ How I Solved Them

* Repeated each command several times in a practice environment.
* Verified results using `ls` and `pwd` after every major step.
* Used `find` to confirm that files had been moved or copied correctly.

---

# 💡 Key Learnings

* Linux file management is one of the most fundamental skills for any Cloud or DevOps Engineer.
* Organizing directories properly makes systems easier to maintain.
* Understanding commands like `cp`, `mv`, `rm`, and `find` is essential for day-to-day Linux administration.
* Verifying changes after every command helps prevent mistakes and builds confidence.
