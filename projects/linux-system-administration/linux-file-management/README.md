# 📂 Linux File Management Challenge

A hands-on Linux project that demonstrates essential file and directory management operations through a real-world business scenario.

This project simulates the day-to-day responsibilities of a Linux Administrator, including organizing company data, managing files and directories, creating backups, searching files, managing permissions, and compressing data using Linux commands.

---

## 🏢 Project Scenario

Imagine you've joined **ABC Technologies** as a **Junior Linux Administrator**.

Your manager assigns you the task of organizing files for different departments, maintaining a structured directory hierarchy, creating backups, managing project files, and ensuring everything is organized according to company standards.

---

## 🎯 Objectives

- Practice Linux file and directory management
- Learn common Linux file operations
- Organize departmental data efficiently
- Create and manage backups
- Search files and content using Linux commands
- Manage basic file permissions
- Archive and compress project data

---

## 🛠️ Commands Used

| Category | Commands |
|----------|----------|
| Navigation | `pwd`, `ls`, `ls -l`, `cd` |
| File & Directory Management | `mkdir`, `touch`, `cp`, `cp -r`, `mv`, `rm`, `rmdir`, `rm -r` |
| File Viewing | `cat`, `less`, `echo` |
| Search | `find`, `grep`, `wc` |
| Disk Usage | `du`, `df` |
| Permissions | `chmod` |
| Archive & Compression | `tar`, `gzip` |
