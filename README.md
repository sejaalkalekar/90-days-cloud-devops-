# 👋 Welcome

Welcome to my **90 Days of Cloud & DevOps** repository.

I'm documenting my learning journey publicly while strengthening my skills in **AWS, Linux, Docker, DevOps, and Cloud Engineering** through hands-on labs, real-world projects, and consistent daily practice.

The goal isn't just to complete 90 days—it's to build practical skills, create a portfolio of projects, and share everything I learn along the way.

- ✅ Strengthen Linux fundamentals
